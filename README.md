## 🚀 Как загрузить сайт на Vercel (Бесплатно и за 2 минуты)

У вас есть два очень простых способа опубликовать сайт:

### Способ 1. Через сайт Vercel (Самый простой — без терминала)
1. Зарегистрируйтесь или войдите на [vercel.com](https://vercel.com).
2. Создайте репозиторий на [GitHub](https://github.com/new) (например `ira-birthday-21`) и загрузите туда файлы из этой папки (`index.html`, `vercel.json` и ваши фотографии).
3. На сайте Vercel нажмите кнопку **«Add New...» → «Project»**.
4. Выберите ваш GitHub-репозиторий и нажмите **«Deploy»**.
5. Через 15 секунд Vercel выдаст вам готовую красивую ссылку (например `ira-birthday.vercel.app`), которую вы сможете отправить жене!

### Способ 2. Через Vercel CLI (Через командную строку)
1. Убедитесь, что установлен Node.js, и выполните в терминале в этой папке:
   ```bash
   npm i -g vercel
   vercel
   ```
2. Следуйте подсказкам (нажмите Enter на всех шагах) — проект мгновенно загрузится в сеть.
